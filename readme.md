# CineMax CESDE 🎬

Proyecto integrador desarrollado para el programa de Desarrollo de Software CESDE 2026.

## Descripción

CineMax CESDE es un sistema web orientado a la gestión básica de un cine, integrando:

- Frontend en HTML y CSS
- Diseño responsive con Bootstrap
- Lógica de programación en Java
- Base de datos en SQL Server
- Operaciones CRUD
- Modelo Entidad Relación (MER)

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Java
- SQL Server
- Git y GitHub

## Módulos desarrollados

- Página de inicio
- Servicios
- CRUD de películas
- Base de datos y MER
- Lógica de programación
- Contacto
- Integrantes
