Modelo Entidad Relación (MER)

Descripción del Modelo

El sistema CineMax CESDE permite administrar películas, salas de cine, clientes, funciones y tickets.

Las tablas se relacionan mediante llaves primarias y llaves foráneas para mantener la integridad de los datos.

Ejemplo Script SQL

CREATE TABLE tblPeliculas (
    PeliculaId int primary key identity(1,1),
    Titulo varchar(100) not null,
    DuracionMinutos int not null,
    PrecioBase money not null,
    ClasificacionEdad char(5) not null,
    Genero varchar(30) not null
);

CREATE TABLE tblSalas (
    SalaId int primary key identity(1,1),
    NombreSala varchar(30) not null,
    Capacidad int not null
);
