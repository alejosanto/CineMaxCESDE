Descripción del Ejercicio

El sistema permite calcular el valor de una compra de tickets, validar la edad mínima del comprador y aplicar descuentos dependiendo del subtotal de la compra.

Pseudocódigo

Inicie

Leer nombre
Leer cantidadTickets
Leer edad

precioBase = 10000
clasificacionEdad = "R"

subtotal = cantidadTickets * precioBase

Si subtotal > 50000 Entonces
    descuento = subtotal * 0.10
Sino
    descuento = 0
FinSi

precioTotalPagado = subtotal - descuento

Si edad >= edadMinima Entonces
    mensajeCompra = "Compra aprobada"
Sino
    mensajeCompra = "Compra rechazada"
FinSi

Imprimir mensajeCompra
